# サポートマトリクス

## ランタイム

| ランタイム | バージョン | ステータス |
|-----------|-----------|-----------|
| Bun       | 1.3.x     | サポート（CI テスト済み） |
| Bun       | 1.4.x     | 計画中 |
| Node.js   | 22.x      | Lambda のみ（`createLambdaHandler` 経由） |

## データベース

| データベース | バージョン | ステータス |
|------------|-----------|-----------|
| PostgreSQL | 14+       | サポート（プライマリ） |
| SQLite     | 3.x       | サポート（Bun ネイティブ経由） |
| MySQL      | 8.x       | サポート（`createMySqlDatabase` 経由） |
| Aurora Serverless v2（Data API） | PostgreSQL 14+ | サポート（`createAwsDataApiDatabase` 経由） |

## オプションサービス

| サービス | バージョン | 必須 | 用途 |
|---------|-----------|------|------|
| Redis   | 7.x       | No   | キュー、キャッシュ、セッション、ブロードキャスト、レート制限 |

## レンダリングモード

| モード | ステータス |
|-------|-----------|
| SSR   | サポート（blog サンプルのデフォルト） |
| SPA   | サポート |

## CI カバレッジ

- 全 PR: Bun 1.3.x、外部 DB なし（モック）、Redis サービス
- ナイトリー: PR と同等に加えて、実データベースに対するフルランタイムスモークテスト・セキュリティ監査・スキャフォールドからビルドまでのE2E検証
- リリース: 公開前にフル検証
