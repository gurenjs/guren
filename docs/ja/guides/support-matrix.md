# サポートマトリクス

## ランタイム

| ランタイム | バージョン | ステータス |
|-----------|-----------|-----------|
| Bun       | 1.4.x     | サポート（CI テスト済み、主対象） |
| Bun       | 1.3.x     | ベストエフォート（CI ではテストしない） |
| Node.js   | 22.x      | Lambda のみ（`createLambdaHandler` 経由） |

## データベース

| データベース | バージョン | ステータス |
|------------|-----------|-----------|
| PostgreSQL | 14+       | サポート（プライマリ） |
| SQLite     | 3.x       | サポート（Bun ネイティブ経由） |
| MySQL      | 8.x       | サポート（`createMySqlDatabase` 経由） |
| Aurora Serverless v2（Data API） | PostgreSQL 14+ | サポート（`createAwsDataApiDatabase` 経由） |

## ライブラリ

| ライブラリ | バージョン | ステータス |
|-----------|-----------|-----------|
| Zod       | 4.x(zod 4 API) | サポート。zod v3 API(`zod@3` または `zod/v3` サブパス)で書かれたスキーマは、codegen・OpenAPI 生成・`guren context` が警告付きで拒否します — [バリデーション](./validation.md) を参照 |

## オプションサービス

| サービス | バージョン | 必須 | 用途 |
|---------|-----------|------|------|
| Redis   | 7.x       | No   | キュー、キャッシュ、セッション、ブロードキャスト、レート制限 |

## レンダリングモード

| モード | ステータス |
|-------|-----------|
| SSR   | サポート（blog サンプルのデフォルト） |
| SPA   | サポート |

## CI カバレッジ

- 全 PR: Bun 1.4.x。Redis・PostgreSQL・MySQL のサービスを立てて統合テストを実行
- ナイトリー: Bun 1.4.x のみ。PR と同じテストに加えて、実データベースに対するフルランタイムスモークテスト・セキュリティ監査・スキャフォールドからビルドまでの E2E 検証
- リリース: 公開前にフル検証
