# サポートマトリクス

## ランタイム

| ランタイム | バージョン | ステータス |
|-----------|-----------|-----------|
| Bun       | 1.4.x     | サポート（CI テスト済み、主対象） |
| Bun       | 1.3.x     | ベストエフォート（CI ではテストしない） |
| Node.js   | 22.x      | Lambda のみ（`createLambdaHandler` 経由） |

## データベース

| データベース | バージョン | ステータス |
|------------|-----------|-----------|
| PostgreSQL | 14+       | サポート（プライマリ） |
| SQLite     | 3.x       | サポート（Bun ネイティブ経由） |
| MySQL      | 8.x       | サポート（`createMySqlDatabase` 経由） |
| Aurora Serverless v2（Data API） | PostgreSQL 14+ | サポート（`createAwsDataApiDatabase` 経由） |

## ライブラリ

| ライブラリ | バージョン | ステータス |
|-----------|-----------|-----------|
| Zod       | 4.x(zod 4 API) | サポート。zod v3 API(`zod@3` または `zod/v3` サブパス)で書いたスキーマは、codegen・OpenAPI 生成・`guren context` が警告を出して受け付けません。詳しくは[バリデーション](./validation.md)を参照してください |

## オプションサービス

| サービス | バージョン | 必須 | 用途 |
|---------|-----------|------|------|
| Redis   | 7.x       | 不要 | キュー、キャッシュ、セッション、ブロードキャスト、レート制限 |

## レンダリングモード

| モード | ステータス |
|-------|-----------|
| SSR   | サポート（blog サンプルのデフォルト） |
| SPA   | サポート |

## CI カバレッジ

- すべての PR: Bun 1.4.x で、Redis・PostgreSQL・MySQL のサービスを立てて統合テストを実行します
- ナイトリー: Bun 1.4.x だけで実行します。PR と同じテストに加え、実データベースを使ったランタイム全体のスモークテスト、セキュリティ監査、雛形生成からビルドまでの E2E 検証を行います
- リリース: 公開前にすべての検証を実行します
