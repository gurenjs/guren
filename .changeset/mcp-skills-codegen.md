`guren codegen` publishes an app's MCP skills, and `guren make:mcp-skill` scaffolds one (RFC 0042 §1). A skill is a directory holding a `SKILL.md` under `resources/skills/`, or under `modules/<name>/resources/skills/` for a module, whose name becomes the skill's path prefix. Codegen writes `.guren/mcp-skills.gen.ts`, the `{ files, binary }` module that `mcpPlugin({ skills: { files: () => import('@/.guren/mcp-skills.gen') } })` serves: every regular file below a skill's directory, UTF-8 files as text and any other as base64, with dotfiles, symlinks and directories that hold no `SKILL.md` left out. The module is written once a skill exists and is rewritten empty, never removed, after the last one goes, so the configured `import()` keeps resolving. The Vite plugin regenerates it when a file under a skills directory changes. `make:mcp-skill <name> [--description <text>] [--module <name>]` writes the `SKILL.md` with its frontmatter, refuses a name outside the Agent Skills rule (1 to 64 lowercase letters, digits and single hyphens), and prints the `skills` option to add when the app's `mcpPlugin()` calls carry none. The MCP Skills guide documents both, and what every token of the app can read.
