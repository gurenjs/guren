`guren change:lane` reads an edit to a file an approved, open plan added as that plan's addition (RFC 0040 §3): when the plan's baseline commit did not have the file, the merge base descends from that commit, and every route's security record was compared, the edit is `file-added` (marked `planAddition`, in `record.json` too), held to the check the file's addition takes, and `low` where it passes. A baseline commit the clone lacks or the history does not lead to, and an edited policy, keep the edit `medium`.
