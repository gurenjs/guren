`guren change:lane` reads an edit to a file an approved, open plan added as that plan's addition (RFC 0040 §3): when the commit the plan was approved at did not have the file and the merge base descends from it, the edit is `file-added`, held to the check the file's addition takes, and `low` where it passes. A commit the clone lacks keeps the edit `medium`.
