The App MCP endpoint now serves the MCP 2026-07-28 protocol as well as clients that open with the 2025-era `initialize` handshake, from the same path (RFC 0028). The plugin runs on MCP TypeScript SDK v2: `@modelcontextprotocol/server` replaces `@modelcontextprotocol/sdk` as its dependency. Authentication, scopes, approvals, rate limits and the audit trail are unchanged, and no configuration changes.

**Behaviour changes on the endpoint:** after authentication, a `GET` or `DELETE` answers `405` (there is no session stream to open), and a `POST` whose `Content-Type` is not `application/json` answers `415`.
