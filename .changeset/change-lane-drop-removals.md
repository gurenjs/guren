`guren change:lane` lowers a deleted source file to `low` when one open plan drops the element that owns its path: a root model, resource, controller or side effect at the path `plan:scaffold` would write it, whose base file declared the element's name (RFC 0040 §3). `source-removed` is now declarable, and a deleted file that is not source is `non-source-removed`, which stays `medium`.
