`guren change:lane` reads a deleted source file as `file-removed`, declarable to `low`, when one open plan drops the element that owns its path: a root model, resource, controller or side effect at the path `plan:scaffold` would write it, whose base file was that class and nothing else, with no twin or directory index left at the head (RFC 0040 §3). Any other deletion stays `source-removed` at `medium`, and a raise `guren.review.ts` sets for `source-removed` still reaches a declared one.
