Add the attachments layer (RFC 0013, Part 1): `configureAttachments()`, the
`Attachable` model mixin with `hasOneAttached`/`hasManyAttached`
declarations typed on the model (collection names, one/many kinds, and
variant names are compile-time checked), and the
attach/detach/withAttachments/attachmentUrl/purgeAttachments statics.
Image uploads pass a three-gate pipeline (byte cap, dependency-free header
dimension check, full decode) with HEIC rejected by default; variants are
generated by a Bun-native `Bun.Image` processor resolved via feature
detection, with a pluggable `ImageProcessor` interface and graceful
degradation (per-variant status records, URL fallback to the original) on
runtimes without one.
