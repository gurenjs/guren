`guren deps:exposure` shows which routes and files reach each installed package (RFC 0039 §4). It reads the app's runtime imports (type-only ones skipped, a literal `import.meta.glob()` and the scaffolded page resolver expanded), follows the app's own files from each Application Graph node, and joins those nodes to routes through `handles`, `renders` (for the action that renders the page), `binds`, `usesMiddleware`, `validates` and `authorizes`. A package the client or SSR entry reaches is attributed to every route that renders a page. A package is reached through the files importing it, or the files importing the direct dependency that brings it in. A package only `@guren` packages bring in is reported once as `framework` rather than spread over every route. Each entry says where its importers run (server, client, ssr, build, test) and whether the routes it reaches require a signed-in user; `none-found` and `unknown` tell a package nothing reaches from one a reader could not see. `--package <name>` narrows the output, `--json` prints the versioned document with coverage per reader and a snapshot fingerprinted before and after collection, and the command exits 1 while a reader is incomplete or a file changed during the run.
