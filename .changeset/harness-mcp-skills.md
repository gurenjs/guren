The agent harness covers MCP skills. The `agent-interface` skill gains a section on publishing a skill for the agents that call the app (`make:mcp-skill`, `codegen`, the `skills` option of `mcpPlugin()`, who can read a skill, and the `mcp-skill-*` checks), and the `scaffold` skill lists the command. Run `bunx guren agent:sync` to refresh an installed harness.
