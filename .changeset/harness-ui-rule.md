The agent harness ships a `ui.md` rule, loaded when an agent edits `resources/js/**` or `resources/css/**`: the `--g-*` design tokens and their `g-` utilities, the red budget (one accent-filled primary action per screen; a destructive action is an outlined explicit verb, filled red only inside a confirm step), dark mode through the tokens rather than raw colors or `dark:` pairs, and the class strings `make:feature` and `make:auth` emit. `agent:sync` installs it in existing apps and replaces a `rules/ui.md` the app already keeps, so an app with its own should run `agent:sync --dry-run` first.
