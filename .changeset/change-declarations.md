`guren change:lane` and `guren change:evidence` now lower a fact an approved, open plan declares (RFC 0040 §3). An added source file that `plan:scaffold` writes for an element the plan adds, at that path and exporting what the scaffold's own output exports, and an added table of a model the plan adds, with exactly its planned columns, are `low`, and the report names the plan and the element (`declared by docs/plans/comments/plan.json#model.comment`). `record.json` carries it as `declaredBy`. Nothing is declared in a change that writes a plan record, and a subject two open plans both claim stays where it was.

A routes file, a migration, an altered table, a removed file, a file a plan's `commands` write and an edit to a file an earlier task of the plan added stay `medium` for now, and so does `db/schema.ts` when a table's default or index config is written as a function (the scaffold's own output does this).
