'@guren/cli': minor
---

`guren check`, `guren audit` and `guren tool:list` read an app's MCP skills (RFC 0042 §1.6). `check` gains a group that is silent until an app has a skill, a generated `.guren/mcp-skills.gen.ts` or an import of it: `mcp-skill-frontmatter:<file>` fails a skill the endpoint would leave out, judged by the MCP SDK's own catalog call over the contents codegen publishes, so the check and the server agree; `mcp-skill-manifest:<file>` fails a manifest spelled in another case; `mcp-skill-namespace:<file>` fails a `SKILL.md` below another skill's directory and a root skill named after a module with skills; `mcp-skill-limit:<file>` fails a skill over 512 files or 16 MiB; `mcp-skills-stale` fails a generated module that is missing or differs from the files, with `check --fix` running codegen; `mcp-skills-unserved` warns when no `mcpPlugin()` call carries `skills`, and is reported as unverified, never passed, for a call it cannot read whole; `mcp-skill-host-limit` is advisory, for a text file over 100 KB, a skill over 400 KB or more than 100 skills. `audit`'s hardcoded-credential scan now covers the text files of every published skill, which any API token of the app can read. `tool:list` prints the skills the endpoint would serve below the tools, including for an app with no tools, and `--json` carries them as `skills`. `@guren/cli` now requires `@modelcontextprotocol/server` 2.4.0 or later, the release that ships the Skills extension.
